# Mira MVP 实施计划

> **给后续 Agent 工作者：** 实施本计划时必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`。本文件使用 checkbox 语法追踪进度。

**目标：** 构建一个本地优先的开发者 Agent 记忆中枢，支持保存会话、提炼项目记忆、搜索记忆，并通过 CLI 与 MCP Server 把相关上下文提供给 Codex、Claude Code、Cursor、OpenClaw 等编码 Agent。

**架构：** Mira 第一版采用 Node.js + TypeScript + SQLite。CLI 是人类使用入口，MCP Server 是 Agent 使用入口。记忆提炼先用确定性规则跑通闭环，后续再接入 LLM 做更智能的总结、归并和重要性判断。

**技术栈：** TypeScript、Node.js、SQLite FTS5、`better-sqlite3`、`commander`、`vitest`、`tsx`、MCP TypeScript SDK。

---

```markdown
# Mira MVP

Mira 是一个本地优先的开发者 Agent 记忆中枢，第一用户是这台机器的拥有者。

## 第一承诺

当我在 Codex、Claude Code、Cursor、OpenClaw 或其他编码 Agent 之间切换时，Agent 能恢复关键项目上下文，而不需要我反复解释。

## MVP 范围

- 保存 Agent 会话为项目关联 thread。
- 从会话中提炼长期有效的项目记忆。
- 搜索项目记忆。
- 为当前项目生成 context bundle。
- 通过 CLI 暴露保存、提炼、搜索、上下文生成能力。
- 通过 MCP tools 暴露搜索和上下文能力。
- 使用 SQLite 本地存储。
- 支持 Markdown / JSON 导出。

## 暂不做

- 多用户账号。
- 云同步。
- 计费。
- 官网或公开 Web App。
- 插件市场。
- 团队空间。
- 通用消费者个人记忆。
```

import Database from "better-sqlite3";
import { mkdirSync } from "node:fs";
import { dirname } from "node:path";

export function openDatabase(path: string): Database.Database {
  if (path !== ":memory:") {
    mkdirSync(dirname(path), { recursive: true });
  }
  return new Database(path);
}

- 覆盖范围：本计划覆盖本地存储、项目空间、会话保存、记忆提炼、搜索、上下文包、CLI 和 MCP。云同步、UI、多用户账号、通用个人记忆不在 MVP 范围内。
- 占位扫描：没有保留 `TBD`、`TODO` 或“以后实现”式占位任务。
- 类型一致性：对外 TypeScript API 使用 camelCase，SQLite 字段使用 snake_case。`Project`、`Thread`、`Memory` 的字段名在后续任务中保持一致。
