## Project Context

This session established the early direction for Mira.

Mira is a personal developer-agent memory hub. Its first user is the project owner, not a broad consumer audience. The project should prioritize continuity across coding agents such as Codex, Claude Code, Cursor, and OpenClaw.

## Key Decisions

- Product name: Mira.
- Core positioning: personal agent memory infrastructure for developer workflows.
- First-stage goal: make it unnecessary to re-explain project context when switching agents or sessions.
- Initial scope: developer-agent memory before general personal AI memory.
- Recommended storage direction: SQLite plus FTS first, with JSON/Markdown export; vector search and graph capabilities can come later.
- Useful Rowboat inspiration: local knowledge generation, human-auditable Markdown memory, background memory distillation, and MCP/tool integration.
- Deferred scope: public website, plugin marketplace, multi-user accounts, billing, team spaces, complex onboarding, and broad general-knowledge UI.

## MVP Shape

The suggested MVP is a local personal agent memory hub with:

- `save-thread`: save an agent session as a thread.
- `distill-memory`: extract durable project memory from a thread.
- `search-memory`: search prior conclusions in natural language.
- `context-bundle`: inject relevant project memory into new sessions.
- `working-memory`: track the most important current projects, tasks, preferences, and recent decisions.
- `project space`: isolate memory by repository or workspace.
